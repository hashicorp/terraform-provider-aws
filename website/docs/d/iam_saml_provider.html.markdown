# Data Source: aws_iam_saml_provider

This data source can be used to fetch information about a specific
IAM SAML provider. This will allow you to easily retrieve the metadata
document of an existing SAML provider.

## Example Usage

```terraform
data "aws_iam_saml_provider" "example" {
  arn = "arn:aws:iam::123456789:saml-provider/myprovider"
}
```

## Argument Reference

This data source supports the following arguments:

* `arn` - (Required) ARN assigned by AWS for the provider.

## Attribute Reference

This data source exports the following attributes in addition to the arguments above:

* `context_provider` - Trusted identity propagation context provider configuration. See [`context_provider`](#context_provider) below.
* `create_date` - Creation date of the SAML provider in RFC1123 format, e.g. `Mon, 02 Jan 2006 15:04:05 MST`.
* `identity_center_instance_arn` - ARN of the IAM Identity Center instance that validates the identity.
* `identity_store_arn` - ARN of the identity store associated with the IAM Identity Center instance.
* `name` - Name of the provider.
* `saml_key_hashes` - Key hashes for each SAML identity provider issuer. See [`saml_key_hashes`](#saml_key_hashes) below.
* `saml_metadata_document` - The XML document generated by an identity provider that supports SAML 2.0.
* `saml_provider_uuid` - Unique identifier assigned to the SAML provider.
* `tags` - Tags attached to the SAML provider.
* `valid_until` - Expiration date and time for the SAML provider in RFC1123 format, e.g. `Mon, 02 Jan 2007 15:04:05 MST`.

### context_provider

* `key_definition` - Mappings from keys in the SAML assertion to trusted context keys. See [`key_definition`](#key_definition) below.
* `subject_source_key` - Key in the SAML assertion that supplies the subject.
* `subject_type_source_key` - Key in the SAML assertion that supplies the subject type.
* `subject_type_value` - Static value for the subject type.

### key_definition

* `source_key` - Key in the SAML assertion the value is read from.
* `target_key` - Trusted context key the value is mapped into.

### saml_key_hashes

* `issuer_url` - Issuer URL of the SAML identity provider.
* `key_hashes` - List of key hashes for the issuer.
