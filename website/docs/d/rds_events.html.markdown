# Data Source: aws_rds_events

Provides details about RDS events, as recorded in the RDS event stream. RDS
records events such as maintenance and failure notifications that are not
always surfaced by the AWS API as errors. This data source is a thin wrapper
over the `DescribeEvents` API and does not evaluate or interpret the events it
returns.

Events are time-windowed and non-deterministic: the `events` attribute
reflects a wall-clock window at read time. If you use this data source to
inspect events generated by another resource's most recent apply, add a
`depends_on` on that resource so the read happens after the operation you're
investigating, and be aware that a subsequent `terraform plan`/`refresh` will
re-read a different (later) window.

## Example Usage

```terraform
data "aws_rds_events" "example" {
  source_identifier = aws_db_instance.example.identifier
  source_type       = "db-instance"
  event_categories  = ["failure", "maintenance"]

  depends_on = [aws_db_instance.example]
}
```

## Argument Reference

This data source supports the following arguments:

* `duration` - (Optional) Number of minutes to look back from now. Conflicts with `start_time` and `end_time`.
* `end_time` - (Optional) End of the time interval, in RFC3339 format. Conflicts with `duration`.
* `event_categories` - (Optional) Set of event categories to filter on, e.g. `failure`, `maintenance`, `configuration change`. Defaults to all categories.
* `region` - (Optional) Region where this resource will be [managed](https://docs.aws.amazon.com/general/latest/gr/rande.html#regional-endpoints). Defaults to the Region set in the [provider configuration](https://registry.terraform.io/providers/hashicorp/aws/latest/docs#aws-configuration-reference).
* `source_identifier` - (Optional) Identifier of the source, such as a DB instance or DB cluster identifier. Requires `source_type` to also be set.
* `source_type` - (Optional) Type of source. Valid values include `db-instance`, `db-cluster`, `db-snapshot`, `db-parameter-group`, `db-security-group`, `db-cluster-snapshot`, `custom-engine-version`, `db-proxy`, `blue-green-deployment`, `db-shard-group`, and `zero-etl`.
* `start_time` - (Optional) Start of the time interval, in RFC3339 format. Conflicts with `duration`.

## Attribute Reference

This data source exports the following attributes in addition to the arguments above:

* `events` - List of events. See [`events`](#events-block) below.

### `events` Block

* `date` - Date and time of the event, in RFC3339 format.
* `event_categories` - List of categories for the event.
* `message` - Text of the event.
* `source_arn` - ARN of the event source.
* `source_identifier` - Identifier of the event source.
* `source_type` - Type of the event source.
