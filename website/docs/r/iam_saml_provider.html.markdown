# Resource: aws_iam_saml_provider

Provides an IAM SAML provider.

## Example Usage

```terraform
resource "aws_iam_saml_provider" "default" {
  name                   = "myprovider"
  saml_metadata_document = file("saml-metadata.xml")
}
```

## Argument Reference

This resource supports the following arguments:

* `context_provider` - (Optional) Configures how claims in the SAML assertion become session context, enabling [trusted identity propagation](https://aws.amazon.com/blogs/security/know-the-identity-behind-the-role-authorize-and-audit-with-trusted-identity-propagation/). See [`context_provider`](#context_provider) below.
* `identity_center_instance_arn` - (Optional) ARN of the IAM Identity Center instance that validates the identity. Requires `context_provider`.
* `name` - (Required) The name of the provider to create.
* `saml_metadata_document` - (Required) An XML document generated by an identity provider that supports SAML 2.0.
* `tags` - (Optional) Map of resource tags for the IAM SAML provider. If configured with a provider [`default_tags` configuration block](https://registry.terraform.io/providers/hashicorp/aws/latest/docs#default_tags-configuration-block) present, tags with matching keys will overwrite those defined at the provider-level.

### context_provider

* `key_definition` - (Optional) Mappings from keys in the SAML assertion to trusted context keys. Up to 10 blocks. See [`key_definition`](#key_definition) below.
* `subject_source_key` - (Required) Key in the SAML assertion that supplies the subject. Keys can contain only ASCII letters, numbers, single spaces, and the characters `_ . : / = + - @ #`, and can't start or end with a space.
* `subject_type_source_key` - (Optional) Key in the SAML assertion that supplies the subject type. Conflicts with `subject_type_value`.
* `subject_type_value` - (Optional) Static value for the subject type, such as `user` or `workload`. Conflicts with `subject_type_source_key`.

### key_definition

* `source_key` - (Required) Key in the SAML assertion to read the value from.
* `target_key` - (Optional) Trusted context key to map the value into. Defaults to the value of `source_key`.

## Attribute Reference

This resource exports the following attributes in addition to the arguments above:

* `arn` - The ARN assigned by AWS for this provider.
* `identity_store_arn` - ARN of the identity store associated with the IAM Identity Center instance.
* `saml_key_hashes` - Key hashes for each SAML identity provider issuer. See [`saml_key_hashes`](#saml_key_hashes) below.
* `saml_provider_uuid` - Unique identifier assigned to the SAML provider.
* `tags_all` - A map of tags assigned to the resource, including those inherited from the provider [`default_tags` configuration block](https://registry.terraform.io/providers/hashicorp/aws/latest/docs#default_tags-configuration-block).
* `valid_until` - The expiration date and time for the SAML provider in RFC1123 format, e.g., `Mon, 02 Jan 2006 15:04:05 MST`.

### saml_key_hashes

* `issuer_url` - Issuer URL of the SAML identity provider.
* `key_hashes` - List of key hashes for the issuer.

## Import

In Terraform v1.12.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `identity` attribute. For example:

```terraform
import {
  to = aws_iam_saml_provider.example
  identity = {
    "arn" = "arn:aws:iam::123456789012:saml-provider/ExampleProvider"
  }
}

resource "aws_iam_saml_provider" "example" {
  ### Configuration omitted for brevity ###
}
```

### Identity Schema

#### Required

- `arn` (String) ARN of the IAM SAML provider.

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import) to import IAM SAML Providers using the `arn`. For example:

```terraform
import {
  to = aws_iam_saml_provider.default
  id = "arn:aws:iam::123456789012:saml-provider/SAMLADFS"
}
```

Using `terraform import`, import IAM SAML Providers using the `arn`. For example:

```console
% terraform import aws_iam_saml_provider.default arn:aws:iam::123456789012:saml-provider/SAMLADFS
```
