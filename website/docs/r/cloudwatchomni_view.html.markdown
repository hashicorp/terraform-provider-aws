# Resource: aws_cloudwatchomni_view

Manages an Amazon CloudWatch Omni view.

A view is a named, reusable SQL query over CloudWatch telemetry. It stores the query, not the data: each time the view is queried, its definition runs against the underlying data. See the [CloudWatch SQL query reference](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/omni-sql-query-reference.html) for the query syntax.

## Example Usage

### Basic Usage

```terraform
resource "aws_cloudwatchomni_view" "example" {
  name       = "view.app_errors"
  definition = "SELECT `@timestamp`, `@message` FROM \"logs.default\" WHERE `@logGroupName` = '/my/app'"
}
```

### With Description and Tags

```terraform
resource "aws_cloudwatchomni_view" "example" {
  name        = "view.app_errors"
  definition  = "SELECT `@timestamp`, `@message` FROM \"logs.default\" WHERE `@logGroupName` = '/my/app'"
  description = "Error lines from /my/app"

  tags = {
    team = "payments"
  }
}
```

### Querying a View

Reference a view by name in the `FROM` clause of a telemetry query, quoting the name because it contains a dot (for example, `FROM "view.app_errors"`). Bound `@timestamp` on both sides in the `WHERE` clause; the service rejects queries with an open-ended time range.

## Argument Reference

The following arguments are required:

* `definition` - (Required) SQL query that defines the view. Must be 1 to 10000 characters. The service validates the query when the view is created or updated.
* `name` - (Required) Name of the view. Must start with `view.` followed by a lowercase letter or digit, contain only lowercase letters, digits, underscores and hyphens, and be 6 to 256 characters long. Unique within the account and Region. Changing this value forces replacement.

The following arguments are optional:

* `description` - (Optional) Description of the view. Must be 1 to 1024 characters.
* `region` - (Optional) Region where this resource will be [managed](https://docs.aws.amazon.com/general/latest/gr/rande.html#regional-endpoints). Defaults to the Region set in the [provider configuration](https://registry.terraform.io/providers/hashicorp/aws/latest/docs#aws-configuration-reference).
* `tags` - (Optional) Map of tags assigned to the resource. If configured with a provider [`default_tags` configuration block](/docs/providers/aws/index.html#default_tags-configuration-block) present, tags with matching keys will overwrite those defined at the provider-level.

## Attribute Reference

This resource exports the following attributes in addition to the arguments above:

* `arn` - ARN of the view. Contains an identifier generated by CloudWatch, in the form `arn:aws:cloudwatch:<region>:<account>:view/<name>/<id>`.
* `tags_all` - Map of tags assigned to the resource, including those inherited from the provider [`default_tags` configuration block](https://registry.terraform.io/providers/hashicorp/aws/latest/docs#default_tags-configuration-block).
* `type` - Type of the view. Views created with Terraform are `USER` views.

## Import

In Terraform v1.12.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `identity` attribute. For example:

```terraform
import {
  to = aws_cloudwatchomni_view.example
  identity = {
    name = "view.app_errors"
  }
}

resource "aws_cloudwatchomni_view" "example" {
  ### Configuration omitted for brevity ###
}
```

### Identity Schema

#### Required

* `name` (String) Name of the view.

#### Optional

* `account_id` (String) AWS Account where this resource is managed.
* `region` (String) Region where this resource is managed.

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import) to import CloudWatch Omni views using the `name`. For example:

```terraform
import {
  to = aws_cloudwatchomni_view.example
  id = "view.app_errors"
}
```

Using `terraform import`, import CloudWatch Omni views using the `name`. For example:

```console
% terraform import aws_cloudwatchomni_view.example view.app_errors
```
